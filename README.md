# testRun2
Create a folder with any name in your file's app. Create three folders inside with names 
“.idea”, “images”, “src”. In the “images” folder add all the files with the extension “.png”, 
“.jpg” or “.jpeg”. In the “src” folder add all the files with the extension “.java”. In the 
“.idea” folder add the files with “.txt” extension and “.xml” extension. And in the main 
folder(next to the .idea, images, src folder) add the “gitignore.txt” file and the 
“testRun2.iml”.
